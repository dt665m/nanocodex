# Nanocodex 0.6.7

This release includes the CLI startup and Hand lifecycle fixes merged since 0.6.6. Fresh CLI runs use one managed request, optional tool preparation overlaps cloud admission, and direct Hand preparation and terminal flushing do less work before the first response. The Hand menu stays responsive during inventory refreshes and retires disconnected runtimes safely.

The terminal adds slash-command autocomplete, scoped `/review`, and saved names and prompts in the resume picker. Managed Claude recovery and captured Bash tool schemas are repaired. Connectors and Vault services are available through REST, hosted forms, JavaScript, and Rust, with a focused Connections and Vault workspace and an official Figma MCP preset.

The release also includes the upstream Sky browser integration and cross-platform Nix packages and system modules.
